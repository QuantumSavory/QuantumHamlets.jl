Certified matching-cost BURY prototype
=====================================

Scope: simple undirected unweighted graphs; one bipartition A,V\A with
exact prescribed cardinality |A|=r. The objective is the cardinality of a
maximum matching in the crossing-edge graph H_A. This is not an edge-cut
or GF(2)-rank approximation guarantee, and it does not directly generalize
to the package's sum over pairs for three or more parts.

Theorem (exact separator characterization).
Let OPT_r be the minimum crossing matching cardinality over |A|=r.
Then OPT_r is the minimum size of a vertex set S for which the component
sizes of G-S have a subset sum t satisfying r-|S| <= t <= r.

Proof, forward direction.
For an optimum A, H_A is bipartite. By Konig's matching-cover theorem it
has a vertex cover S of size OPT_r. There are no crossing edges in G-S.
Hence every connected component of G-S lies entirely in A or entirely
in V\A. The components inside A have total size t=|A\S|, with
r-|S| <= t <= r. Thus the minimum admissible |S| is at most OPT_r.

Proof, reverse direction.
Take a feasible S and a union W of components of G-S of size t in the
specified interval. Put W and any r-t vertices of S into A. This is
possible because 0 <= r-t <= |S|. Then |A|=r, and every crossing edge
has an endpoint in S: no edge joins different components of G-S.
Consequently every crossing matching has at most |S| edges. Therefore
OPT_r <= |S|. Both inequalities give equality.

Algorithm and certificate.
Run production BURY to obtain a feasible partition of matching cost U.
If U=0 it is optimal. Otherwise enumerate S in increasing cardinalities
s=0,...,min(q,U-1), checking the subset-sum condition by a dynamic program.
The first feasible S yields an optimal partition, with cost exactly s:
earlier cardinalities were exhausted, so the theorem proves OPT_r >= s;
the constructed partition has cost at most s. If all searches fail then
OPT_r >= min(q,U-1)+1. The existing BURY partition therefore has the
certified factor U / (min(q,U-1)+1). If this lower bound equals U, BURY
is proved optimal even though no improving separator was found.

In particular, q=0 repairs every zero-cost instance; q=1 additionally
solves every instance with OPT_r=1. This is a useful safeguard against
greedy decisions that overlook a separable balanced partition.

Complexity and limits.
For each S, finding components takes O(n+m), and the elementary subset-
sum dynamic program takes O(n*r). Searching through size q therefore
costs at most O(sum_{s=0}^q binomial(n,s) * (n+m+n*r)), in addition to
BURY and matching evaluation. It is polynomial for fixed q, with an
exponent depending on q; it is not fixed-parameter tractable in q under
this implementation and is not a universal polynomial-time constant
approximation. The formula is a bound, not a performance promise.

For any chosen C>=1, searching through q=ceil(U/C)-1 guarantees a
C-approximation (or finds the optimum earlier), but q may grow linearly
with n. Thus this gives a correct exponential-time constant guarantee,
not the sought efficient worst-case theorem.

Tests (2026-11-11).
Run from the package root:
  julia --startup-file=no --project=. experiments/bury_approximation/certified/runtests.jl

Passed 158,654 assertions: every labeled simple graph n=0..5, all
targets, q=0..min(n,2); 80 deterministic random n=6,8 balanced cases
with q=0..3; validation cases. The independent oracle enumerates all
feasible partitions and, for each, all partial injective left-right
neighbor assignments, rather than calling the package matching routine
or reusing the separator theorem. It verifies optimum, balance,
certificate validity, and graph nonmutation. See results.txt.

All files here are experimental additions. Existing source and tests
were not modified by this prototype.

Component-only guard and maximum degree two.
The additional component_guarded_bury first tries S=empty. If the component
sizes pack to exactly r, it returns the resulting optimal zero-cost cut.
Otherwise it delegates to unchanged ordinary or explicit-seeded BURY.
It validates target, backend, and any seed before running the prepass.

On graphs with maximum degree at most two, the components are isolated
vertices, paths, and cycles. Once BURY purchases a nontrivial closed
neighborhood, it colors an interval in its component. While that component
has uncolored vertices, an unprocessed colored interval endpoint has
residual closed-neighborhood size one. Its purchase extends the interval
by one vertex, leaving the newly colored boundary eligible. Untouched
nontrivial components have residual size at least two, so ordinary BURY
cannot start another before finishing the active component. Isolated
vertices may interleave but add no cut edges. For seeded BURY the boundary
is in the active region, so the same extension argument applies.

There is a small-budget exception to the full-neighborhood invariant. If
a new nontrivial component is entered with only one vertex left, the
algorithm stops after a singleton. If it is entered with two vertices
left but no closed neighborhood of size at most two is available, it
colors one vertex and then an adjacent vertex: adjacent residual sizes
are two while untouched cycle vertices have size three. In ordinary
BURY, any untouched path endpoint of size two would instead have been
chosen initially. In seeded BURY, a size-two vertex already in the region
would likewise have been chosen initially; the neighboring seed-region
candidate after the first singleton has smaller weight than its remaining
nonneighbors. Thus this exception still leaves one contiguous interval.

Accordingly at most one nontrivial component is partly colored, with
at most two crossing edges, for either variant. After the guard failed,
OPT is a positive integer and hence at least one. Since matching cost is
at most edge-cut cost, the returned matching cost is at most 2*OPT. This
is a polynomial-time 2-approximation restricted to maximum degree two,
not a guarantee for arbitrary sparse or bounded-degree graphs.

Additional integration tests: 156 assertions passed in integration.jl;
results in integration.txt. They cover zero-cost component packing that
ordinary BURY misses on disjoint paths of sizes 2,2,3,3; prepass validation
and empty/end targets; exact ordinary/seeded fallback for all backends;
and q=1 exact repairs of the path-hub counterexample with 30,40,80
vertices. On those counterexamples the original matching scores 5,8,14
all become the certified optimum 1.
